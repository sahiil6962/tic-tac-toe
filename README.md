# Tic-Tac-Toe
 
A simple, responsive Tic-Tac-Toe game built with  HTML, CSS, and JavaScript — no frameworks or dependencies required.
 
## 🎮 Demo
 
Open `index.html` in your browser and start playing!
 
## ✨ Features
 
- Classic 3x3 Tic-Tac-Toe gameplay for two players (O and X)
- Automatic winner detection across all 8 win patterns (rows, columns, diagonals)
- Draw detection when the board fills with no winner
- "New Game" and "Reset Game" controls
- Clean, responsive UI that scales with viewport size (`vmin` units)
## 🛠️ Built With
 
- HTML5
- CSS3 (Flexbox)
- JavaScript (Vanilla, ES6)
## 📂 Project Structure
 
```
Javascript/
├── index.html      # Markup and game board layout
├── style.css        # Styling for the board, buttons, and win message
└── tictactoe.js      # Game logic (turns, win detection, reset)
```
 
## 🚀 Getting Started
 
No build step or installation needed.
 
1. Clone or download this repository
2. Open `index.html` directly in any modern web browser
```bash
git clone <your-repo-url>
cd Javascript
open index.html   # or double-click the file
```
 
## 🕹️ How to Play
 
1. Players take turns clicking an empty box on the board — Player O goes first, then Player X
2. The first player to align three matching marks in a row, column, or diagonal wins
3. If all 9 boxes fill up with no winner, the game ends in a draw
4. Click **Reset Game** or **New Game** to start over
